## 两路运气税

```
T1 生成抽卡  — 每 prompt 盲生成 K 个候选挑 1。烧的是 GPU 账单。
T2 验收抽帧  — 均匀抽 N 帧人工/重模型验。烧的是眼睛/算力。
```

IREP 处置：T1 用 **held-out 标定的 verifier**，把盲抽的「真接受率 q」提升为「PPV（被认可即真好）」，期望生成数从 `1/q` 降到 `1/PPV`，减抽卡倍数 = PPV/q。T2 用**帧间不变量（change-point 检测）**：廉价 1D 信号几乎免费全扫时间线，贵的重检只在突变处 zoom。

## 实测结果（20 万次蒙特卡洛，种子 20261016，可复跑）

**T1 生成抽卡**（难 prompt，基础接受率 q = 8%）：

| verifier | held-out Se / Sp | 实标倍数 | 朴素猜「95% 准」 | 判定 |
|---|---|---|---|---|
| 强 verifier | 0.978 / 0.977 | **9.82×** | 7.79× | 保守 −21%（漏报潜力） |
| 中庸 verifier | 0.874 / 0.818 | **3.68×** | 7.79× | **危险 +112% 过度自信** |

中庸那一行是重点：没有 held-out 标定，你不只是少赚——你会**预订一笔从未实现的节省**。

**T2 验收抽帧**（300 帧视频、2% 时长缺陷、95% 抓住置信）：

| 策略 | 需检帧数 | |
|---|---|---|
| 均匀抽帧 | 149 | |
| IREP 自适应（15 帧稀疏安全基线 + 16 帧 zoom × 2 个突变点） | 47 | **3.2×** |

**判据：** 低基率下 PPV 几乎完全由**特异性 Sp** 决定，而 Sp 只能靠 held-out 标定获得——所以标定步骤不是装饰，是承重墙。

视频合成是双用途的。本仓库范围是**验收与溯源，永不涉合成指引**：
